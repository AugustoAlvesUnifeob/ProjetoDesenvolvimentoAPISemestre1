## Resumo:
Criamos uma API que simula um sistema de e-commerce básico, ele permite Criar e Administrar usuários, produtos, e atrelar um carrinho a um usuário para que ele possa colocar produtos dentro.

### Admin:
Contas admin são configuradas manualmente, e algumas funções envolvendo a criação e edição de produtos só podem ser realizadas se a pessoa for admin.

### Sistema:
O sistema possui criação de tokens com o JWT, criação de tabelas com o sequelize e criptografia com o bcrypt
